Back-End & Analytics

아파트 실거래가 분석 기반 가성비 주거지 추천 서비스 (DZTeam4)

팀 프로젝트 (3명) 역할: 팀장 및 Back-End 담당 2026.04.14 ~ 2026.04.24 (10일)

사용 기술 및 환경 (Tech Stack)

Python FastAPI MariaDB MongoDB React Nginx Open API

시스템 아키텍처 및 서비스 흐름도

공공데이터 수집부터 저장 최적화, ARIMA 기반 시세 예측 분석, FastAPI API 엔드포인트를 거쳐 React 프론트엔드로 전달되는 전체 파이프라인 구조입니다.

주요 담당 업무 및 기술적 성과

  • • 대용량 데이터 수집 및 DB 최적화 (약 191만 건):
    공공데이터포털 실거래가 데이터 191만 건을 수집한 후, 캐싱 메모리(Redis) 추가 설치 대신 DB 인덱싱 체계와 스키마 구조 개선만으로 높은 조회 최적화 달성
  • • 인프라 분석 및 ARIMA 예측 모델 기반 가성비 추천 알고리즘:
    강남구 등 주요 고가 지역의 인프라 희소성 지표를 기준점으로 산정하고, 분석 라이브러리와 ARIMA 시계열 예측값을 결합해 가격 대비 높은 인프라 만족도를 갖춘 지역(구 단위) 추천 로직 설계
  • • End-to-End 데이터 분석 파이프라인 설계:
    [데이터 수집 → 저장 및 구조 최적화 → 분석 및 학습 → FastAPI 웹 서비스 제공]으로 이어지는 전체 백엔드 데이터 흐름 구축
