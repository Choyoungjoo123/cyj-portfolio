아파트 분석 서비스 Docker Swarm 컨테이너 환경 이전

팀 프로젝트 (4명) 역할: 팀장 / 3-Tier 컨테이너 이전 및 ES/Kibana 구축 프로젝트 완료

사용 기술 및 환경 (Tech Stack)

Ubuntu 24.04.4 Docker / Docker Swarm Elasticsearch Kibana Harbor Kafka Monitoring

Swarm 클러스터 아키텍처

기존 VMware 기반 서버에서 Master 1대, Worker 2대, Registry(Harbor) 구조의 Docker Swarm 클러스터 환경으로 서비스 전환을 완료한 구성도입니다.

주요 담당 업무 및 기술적 성과

  • • 3-Tier 서비스 컨테이너화 및 Swarm 전환:
    VMware 가상머신 환경의 레거시 구조를 Frontend, Backend, DB가 분리된 3-Tier 구조의 컨테이너 서비스로 재설계 및 Swarm 클러스터로 모던화
  • • Docker Swarm 클러스터 구축 및 프라이빗 레지스트리 운용:
    Master 1노드, Worker 2노드로 구성된 Swarm 오케스트레이션 환경을 구축하고, Harbor 프라이빗 레지스트리를 연동하여 안전한 컨테이너 이미지 버전 관리 수행
  • • Elasticsearch 기반 검색 성능 최적화 및 시각화:
    약 190만 건의 주거 데이터를 Elasticsearch로 인덱싱하여 검색 처리 속도를 대폭 단축하고, Kibana 모니터링 대시보드를 구축하여 실시간 시각화 제공
