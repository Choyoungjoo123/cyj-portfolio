시스템 아키텍처

주요 담당 업무 및 기술적 성과

  • • Ansible을 통한 K8s 클러스터 IaC 자동화 설치:
    Ansible 플레이북을 작성하여 HA 멀티 마스터 쿠버네티스 클러스터 환경의 노드 설치 및 초기 설정을 코드로 관리(IaC)할 수 있도록 자동화 구축
  • • DevSecOps 기반의 GitOps CI/CD 파이프라인 설계:
    GitHub Actions + ArgoCD를 연동하여 소스 코드 커밋부터 클러스터 배포까지 전체 자동화 구성. CI 단계에서 Trivy 이미지 보안 스캔과 SonarQube 정적 코드 분석 품질 게이트(Quality Gate) 적용
  • • Linkerd 서비스 메시 및 Chaos Mesh 인프라 검증:
    Chaos Mesh 기반 카오스 엔지니어링 실험을 진행하여 장애 발생 시 인프라 견고성을 테스트하고, Linkerd 사이드카 프록시를 통해 네트워크 부하와 트래픽 격리 유효성 모니터링 검증
  • • 최적의 오토스케일링 메커니즘 도출:
    부하 테스트 시나리오를 설계하여 CPU 리소스 기반의 기존 HPA와 이벤트 기반 오토스케일러 KEDA의 동작을 비교 검증하고, 서비스 특성에 맞는 최적의 오토스케일링 구조 채택
