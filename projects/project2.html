Data Architecture & Pipeline

TMDB API 기반 영화 데이터 분석 및 다중 DB 파이프라인 구축

팀 프로젝트 (3명) 역할: Data Architect (DA) / DB 설계 및 파이프라인 구축 2026.03.26 ~ 2026.04.13 (19일)

사용 기술 및 환경 (Tech Stack)

MySQL MongoDB Python Rocky Linux 10.1 TMDB REST API

데이터베이스 설계 (ERD Diagram)

정규화된 관계형 데이터(RDB)와 유연한 문서 구조의 비관계형 데이터(NoSQL) 특성에 맞게 다중 데이터베이스 모델링을 진행했습니다.

주요 담당 업무 및 기술적 성과

  • • TMDB REST API 데이터 수집 파이프라인 수립:
    Python 파이프라인을 작성하여 외부 TMDB API로부터 대용량 영화 메타데이터를 안정적으로 수집하고 정제하는 자동화 스크립트 구현
  • • 하이브리드 데이터베이스(RDBMS + NoSQL) 아키텍처 설계:
    정형화된 데이터는 MySQL에, 변경이 잦거나 비정형 요소가 강한 데이터는 MongoDB에 적재하도록 하이브리드 데이터 구조 설계
  • • 쿼리 최적화 및 인덱싱 처리:
    대량 데이터 적재 시 수집 및 조회 속도 저하를 방지하기 위해 데이터 특징에 맞춘 SQL 인덱싱 및 Bulk Insert 쿼리 최적화 적용
